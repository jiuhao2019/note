* flake升级
#+begin_src  sh
cd ~/Downloads/nixos
sudo nix flake update
sudo nixos-rebuild switch
#+end_src
* 更新channel后重新构建
#+begin_src  sh
sudo nixos-rebuild switch --upgrade
#+end_src
* 搜索软件
#+begin_example
nix search nixpkgs firefox
#+end_example

* 查看系统 generations
#+begin_example
sudo nix-env --list-generations --profile /nix/var/nix/profiles/system

会看到类似：

1   2026-08-10  ...
2   2026-08-12  ...
3   2026-08-14  ...
#+end_example
* 查看当前 generation：
#+begin_example
readlink /nix/var/nix/profiles/system
#+end_example
* 回滚系统
** 立即回到上一代：

#+begin_src  sh
sudo nixos-rebuild switch --rollback
#+end_src

** 也可以指定 generation：

#+begin_src  sh
sudo nix-env --profile /nix/var/nix/profiles/system --switch-generation 2
#+end_src

** 然后：

#+begin_src  sh
sudo /nix/var/nix/profiles/system/bin/switch-to-configuration switch
#+end_src

** 如果新配置导致系统无法正常工作，可以在 GRUB/systemd-boot 的 NixOS generations 菜单里直接选择旧 generation。

* 清理旧系统

** 查看垃圾：

#+begin_example
nix-store --gc --print-dead
#+end_example

** 执行垃圾回收：

#+begin_example
sudo nix-collect-garbage
#+end_example

** 删除旧 generations 后再回收：
#+begin_example
sudo nix-collect-garbage -d
#+end_example
** 或者：
#+begin_example
sudo nix-collect-garbage --delete-older-than 30d
例如只保留最近 30 天。
#+end_example
** 如果你经常修改 NixOS 配置，比较推荐：
#+begin_example
sudo nix-collect-garbage --delete-older-than 30d
不要一上来就 -d，因为旧 generation 也提供回滚能力。
#+end_example
* NixOS 配置检查
#+begin_example
sudo nixos-rebuild dry-build
这个很有用：只构建，不实际切换系统。
#+end_example
