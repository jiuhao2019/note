* generation
** 列举 generations
#+begin_example
sudo nix-env --list-generations --profile /nix/var/nix/profiles/system

会看到类似：

1   2026-08-10  ...
2   2026-08-12  ...
3   2026-08-14  ...
#+end_example
** 当前 generation：
#+begin_example
readlink /nix/var/nix/profiles/system
会显示
system-49-link
#+end_example
** 切换generation
*** 立即回到上一代：
#+begin_src  sh
sudo nixos-rebuild switch --rollback
#+end_src

*** 也可以指定 generation：

#+begin_src  sh
sudo nix-env --profile /nix/var/nix/profiles/system --switch-generation 2
 然后： sudo /nix/var/nix/profiles/system/bin/switch-to-configuration switch
#+end_src

*** 如果新配置导致系统无法正常工作，可以在 GRUB/systemd-boot 的 NixOS generations 菜单里直接选择旧 generation。

* 清理旧系统
** 查看垃圾,但不会清理
#+begin_example
nix-store --gc --print-dead
#+end_example
** 删除旧 /nix/store 内容，从而释放磁盘空间
#+begin_example
sudo nix-collect-garbage
#+end_example
** 会删除所有旧的 NixOS system generations，通常只保留当前正在使用的 generation
#+begin_example
sudo nix-collect-garbage -d
#+end_example
** 只保留最近 1 天
#+begin_example
sudo nix-collect-garbage --delete-older-than 1d
#+end_example

* nh使用
先安装：
environment.systemPackages = with pkgs; [
  nh
];
然后重建一次：
sudo nixos-rebuild switch --flake .
之后就可以用 nh。

** 最常用：重建 NixOS

在 nixos配置目录：
nh os switch

** 只构建，不切换
nh os build
不会修改当前正在运行的系统。

** 测试配置
nh os test

** 查看历史配置
nh os info

** 清理旧 generations
保留最近 3 个系统版本，并删除 7 天以前的
nh clean all --keep 3 --keep-since 7d

* lf文件管理器使用

lf 常用快捷键，按“日常使用”来记就够了：

** 方向 / 移动
j / ↓        下移
k / ↑        上移
h / ←        返回上级目录
l / →        进入目录 / 打开文件
gg           跳到顶部
G            跳到底部
Ctrl-d       向下半页
Ctrl-u       向上半页
** 文件操作
Enter        打开文件
y            复制
d            删除
r            重命名
p            粘贴

注意：lf 默认的复制/粘贴是“内部剪贴板”，不是系统剪贴板。

** 选择
Space        选择/取消当前文件
v            反选
uv           取消所有选择
** 搜索 / 跳转
/            搜索文件名
n            下一个匹配
N            上一个匹配
f            快速查找
zh           显示/隐藏隐藏文件

不同版本/配置里隐藏文件常见的是 zh，而不是我上一条说的 .。如果你的 lf 是默认配置，可以直接按 zh。

** 目录跳转
gh           回到 home
g/           根目录
** 排序
os           按大小排序
on           按文件名排序
ot           按修改时间排序
oe           按扩展名排序
** 其他
:            输入 lf 命令
!            执行 shell 命令
$            执行 shell 命令并等待
%            执行 shell 命令并保持 lf
q            退出

** 最值得记的其实就是：

j k        上下
h l        返回/进入
gg G       顶部/底部
Space      选择
y d p r    复制/删除/粘贴/重命名
zh         隐藏文件
/ n N      搜索
q          退出
