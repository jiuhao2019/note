* HID
** HID（Human Interface Device）通用上报
#+begin_example
指的是通过 HID 协议传输设备状态或数据的过程。
在 USB 或蓝牙 HID 设备中，数据上报通常包括按键、鼠标、游戏控制器等设备的输入数据。
HID 协议提供了灵活的方式来传输这些数据，使用不同类型的“上报”（Report）来表示各种输入事件。
#+end_example
** HID 设备分类：
#+begin_example
键盘：发送按键按下和松开的报告。
鼠标：发送移动和点击事件。
游戏控制器：发送按钮按下、摇杆移动等数据。
触摸屏：发送触摸点的坐标和状态。
HID 协议使得设备之间的交互变得非常标准化和简化。对于开发者来说，可以通过理解设备的报告描述符来解析或生成数据，从而实现与设备的通信。
#+end_example
** HID 键盘设备输入报告结构是这样：
#+begin_example
1 字节：修饰符键状态（如 Shift、Ctrl 等）
6 字节：普通按键的状态（每个字节表示一个按键）
#+end_example
#+begin_src  C
typedef struct {
    uint8_t modifier; // 修饰符键状态
    uint8_t reserved;
    uint8_t key[6];   // 6 个按键的状态
} KeyboardReport;
#+end_src
** ASCII 可显示字符的范围,按键可以按出来
*** 可显示字符通常指的是：
- 大小写字母 :: A-Z、a-z（共 52 个字符）
- 数字 :: 0-9（共 10 个字符）
- 标点符号 :: 例如 !"#$%&'()*+,-./:;<=>?@[\\]^_{|}~`（共 32 个字符）
- 格符 :: 1 个字符（空格）
*** 可显示 ASCII 字符的总数
计算总数时，考虑上述各类字符，数量如下：
- 字母 :: 26（大写） + 26（小写） = 52
- 数字 :: 10
- 标点符号 :: 32
- 空格 :: 1
因此，可显示的 ASCII 字符总数是：
52（字母）+ 10（数字）+ 32（标点符号）+ 1（空格）= 95
