* 在 ThreadX 中，优先级数值是“越小越高”。
:PROPERTIES:
:CUSTOM_ID: cf001380-195f-44d1-9d13-8165cc00bc5d
:END:
#+begin_example
具体规则：
0 → 最高优先级
数值越大 → 优先级越低


最大值取决于配置（通常 32 / 64 / 256 级）


示例：


优先级 1 > 优先级 5 > 优先级 10


调度行为：


高优先级任务会立即抢占低优先级任务（前提是可运行）


同优先级任务采用时间片轮转（time-slice）（如果启用）


一个典型误区是把它当作 FreeRTOS 用法：

FreeRTOS：数值越大 → 优先级越高
ThreadX：数值越小 → 优先级越高


一般建议：
实时性强的 AO → 小数字（高优先级）
后台/日志 → 大数字（低优先级）
如果需要，可以帮你把 AO 优先级映射做一套合理分配方案。
#+end_example

#+begin_src  c
  启动操作系统内核
  main.c 文件中包含 threadx 系统头文件 tx_api.h ，并在 while(1) 之前调用 tx_kernel_enter() 函数，此时会报错
  undefined reference to `tx_application_define'

  所以需要自己定义 tx_application_define 这个函数，并在这个函数中启动一个线程来进行 LED 的闪烁，void tx_application_define(void *first_unused_memory)是threadx的入口函数，示例代码如下：
  TX_THREAD                               demo_thread;
  #define DEMO_STACK_SIZE         1024
  static uint8_t thread_stack[DEMO_STACK_SIZE];

  void demo_thread_entry(ULONG thread_input)
  {
      /* This thread simply sits in while-forever-sleep loop.  */
      while(1)
      {
                  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_7, GPIO_PIN_RESET);
                  tx_thread_sleep(1000);
                  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_7, GPIO_PIN_SET);
                  tx_thread_sleep(1000);
      }
  }
  void tx_application_define(void *first_unused_memory)
  {
      /* Create the main thread.  */
      tx_thread_create(&demo_thread,
                                           "demo thread",
                                           demo_thread_entry,
                                           0,
                                           thread_stack,
                                           DEMO_STACK_SIZE,
                                           1,
                                           1,
                                           TX_NO_TIME_SLICE,
                                           TX_AUTO_START);
  }
  编译下载，可以看到 LED 已经成功的闪烁，至此，threadx 已经移植成功
#+end_src
