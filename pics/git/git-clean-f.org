* git clean -f
#+begin_src sh
  git clean -f 是 Git 中的一个命令，用于清理工作区中未跟踪的文件（即未被添加到暂存区的文件）。具体作用是删除那些未被版本控制的文件，但不会影响已经被 Git 跟踪的文件。
  常见用法

      删除未跟踪文件：

  git clean -f

  删除当前目录中所有未被 Git 跟踪的文件。

  删除未跟踪的目录： 默认情况下，git clean 不会删除未被跟踪的目录。如果你想包括目录，可以使用 -d 选项：

  git clean -f -d

  强制删除： 如果你已经启用了 core.safecrlf 或其他保护机制，可能需要添加 -f 以强制执行清理操作。

  仅模拟清理（不会实际删除）： 使用 -n 查看哪些文件会被删除，而不实际执行删除操作：

  git clean -n

  清理忽略规则中包含的文件： 默认情况下，Git 会跳过 .gitignore 文件中定义的文件。如果你希望连这些文件一起清理，添加 -x：

  git clean -f -x

  组合命令： 删除未跟踪的文件、目录以及被忽略的文件：

      git clean -f -d -x

  注意事项

      不可逆性：git clean -f 会永久删除未跟踪的文件或目录，无法通过 Git 恢复。
      谨慎操作：在执行命令前，建议先使用 git clean -n 检查即将删除的文件列表。
      常用场景：
          清理编译生成的临时文件。
          重置工作目录到一个干净的状态。
