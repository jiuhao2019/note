* 二维数组内存
#+begin_src c
int a[3][4]; // 3行4列的二维数组

内存布局：

C语言中，二维数组在内存中是 按行优先（row-major order） 存储的：

也就是说，内存中是按下面的顺序线性排列的：

a[0][0], a[0][1], a[0][2], a[0][3],
a[1][0], a[1][1], a[1][2], a[1][3],
a[2][0], a[2][1], a[2][2], a[2][3]

地址计算公式：

a[i][j] 的地址可以通过以下方式计算：

地址 = 基地址 + sizeof(元素类型) * (i * 列数 + j)

对于上面的 int a[3][4]：

& a[i][j] == &a[0][0] + sizeof(int) * (i * 4 + j)
#+end_src
