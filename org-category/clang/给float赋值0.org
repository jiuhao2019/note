* 给浮点数赋值0
#+begin_example
在 C 语言中，给浮点数赋值 0 有几种常见方式，以下是示例：

float a = 0;       // 合法，隐式转换为 0.0f
float b = 0.0;     // 合法，0.0 是 double，隐式转换为 float
float c = 0.0f;    // 推荐方式，明确是 float 类型常量

double d = 0;      // 合法
double e = 0.0;    // 推荐方式

建议：

    如果变量是 float 类型，建议使用 0.0f，避免从 double 到 float 的隐式转换；

    如果变量是 double 类型，则使用 0.0 即可。

说明：

虽然 0、0.0、0.0f 在语义上都等于 0，但类型不同会影响编译器的行为和警告级别，特别是在开启严格类型检查时。

需要初始化一个浮点数组为 0，也可以使用：

float arr[10] = {0};  // 所有元素都初始化为 0.0f

如有具体场景（比如内存对齐、嵌入式寄存器映射等），可以详细说明以便给出更合适的建议。
#+end_example
