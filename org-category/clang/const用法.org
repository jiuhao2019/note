* const修饰
** const 修饰它左边的东西；如果左边没有，就修饰右边
*** 用这个规则逐个拆
**** const char *p;
***** 读： const 左边没有 → 修饰右边 char      ⇒ char 是 const
***** 结论：
              - 数据不能改
              - 指针能改
**** char * const p;
***** 读： const 左边是 *    ⇒ 指针是 const
***** 结论：
             - 指针不能改
             - 数据能改
**** const char * const p;
***** 拆两次：
                - 第一个 const → 修饰 char
                - 第二个 const → 修饰 *
**** 结论： 都不能改
** 把声明从变量名开始读
*** 示例1
#+begin_src C
  const char *p;
  从 p 开始读：
  p 是一个 → 指针 → 指向 const char
#+end_src

*** 示例2
#+begin_src C
  char * const p;
  从 p 开始读：
  p 是一个 → const 指针 → 指向 char
#+end_src

*** 示例3
#+begin_src C
  const char * const p;
  p 是一个 → const 指针 → 指向 const char
#+end_src
*** 示例4
#+begin_src C
const char *str;
属于：
数据只读（通常在 Flash）
指针可变
所以：
str = "abc";    // ✔
str = "xyz";    // ✔
str[0] = 'A';   // ❌（嵌入式可能直接炸）
#+end_src
** 为什么要这么设计（给你工程理解）
*** 这是为了区分两件完全不同的东西：
                                               - 地址能不能变
                                               - 地址里的内容能不能改
*** 比如
          - Flash → 只能读 → const char *
          - RAM buffer → 可写 → char *
