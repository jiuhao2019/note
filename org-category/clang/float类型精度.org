✅ 关键结论再确认：

    float（4 字节）最多能表示约 6～7 位有效数字，小数部分通常可精确表示约 6 位小数。

这个说法在多数情况下是 准确的，但需要理解"有效数字"和"小数位"的区别：
🔍 一、什么是有效数字（significant digits）？

有效数字指的是一个数中从第一个非零数字开始，到最后一个确定的数字为止，无论小数点在哪里。
示例：

    123.456 有 6 位有效数字

    0.000123456 也有 6 位有效数字

    12345600.0 中的有效数字是前 7 位（如果末尾是确定的）

🔍 二、float 精度的核心限制

根据 IEEE 754 单精度规范（32 位）：

    有效数字： 23 位尾数 + 隐含 1 位，约等于 6～7 位十进制有效数字

    这不是“小数点后固定几位”，而是“总共能精确表示多少位”

❗ 常见误区

    ❌ “float 可以表示 6 位小数” —— 这是不准确的泛化。

实际情况是：

    如果整数部分很大，小数部分就不精确了。

    如果整数部分很小，小数点后可以表示得更多（仍受有效数字限制）。

✅ 举个例子：

#include <stdio.h>

int main() {
    float a = 123456.7890123f;
    printf("%.10f\n", a);  // 输出：123456.7890625000（误差开始出现）
    return 0;
}

虽然你试图保留 6 位小数，但因为整数部分已经占了 6 位有效数字，小数部分只能保留 1 位左右。

再试一个小整数：

float b = 0.1234567f;
printf("%.10f\n", b);  // 输出：0.12345670（很精确）

小数部分能完整保留。
✅ 最终总结
项	float（4 字节）
总有效数字	大约 6~7 位十进制有效数字
小数位最大精度	最多可表示 6~7 位小数，但依赖于整数部分大小
精确场景建议	对精度要求高的，用 double 或使用整数 + 缩放
