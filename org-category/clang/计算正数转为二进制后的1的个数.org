#+begin_src C
          #define BITCOUNT(x)  (((BX_(x)+(BX_(x)>>4)) & 0x0F0F0F0F) % 255)
          #define  BX_(x)      ((x) - (((x)>>1)&0x77777777)            \
                        - (((x)>>2)&0x33333333)            \
                        - (((x)>>3)&0x11111111))

      -- really weird C code to count the number of bits in a word
#+end_src
#+begin_example
这段代码是一个经典的 位计数（population count，popcount） 算法，用于统计一个整数转为二进制形式后有多少个 1。
例如：
BITCOUNT(0b10110100);    // 4
BITCOUNT(0xB4);          // 4
BITCOUNT(180);           // 4
BITCOUNT(0xFFFFFFFF);    // 32
BITCOUNT(0x12345678);    // 统计其中所有 1 的数量
BITCOUNT(a);              // 变量
BITCOUNT(a | b);          // 表达式
BITCOUNT(1 << 5);         // 1
它的时间复杂度是 O(1)，不需要循环。

整体结构
#define BX_(x) \
    ((x) - (((x)>>1)&0x77777777) \
         - (((x)>>2)&0x33333333) \
         - (((x)>>3)&0x11111111))

#define BITCOUNT(x) \
    (((BX_(x)+(BX_(x)>>4)) & 0x0F0F0F0F) % 255)

实际上分两步：

BX_(x)：把每个 nibble（4 bit）变成该 nibble 中 1 的个数。
BITCOUNT(x)：把所有 nibble 的计数累加起来。
第一步：为什么这样减？

假设一个 nibble：

abcd

它表示

a*8+b*4+c*2+d

其中

a,b,c,d ∈ {0,1}

算法计算

x
- ((x>>1)&0x77777777)
- ((x>>2)&0x33333333)
- ((x>>3)&0x11111111)

实际上就是

8a+4b+2c+d
-(4a+2b+c)
-(2a+b)
-a

整理：

=(8-4-2-1)a
 +(4-2-1)b
 +(2-1)c
 +d

=a+b+c+d

也就是说：

每个 nibble 最终变成了该 nibble 中 1 的数量。

这是这个算法最巧妙的地方。

例如

1101

有三个 1。

经过上述计算：

1101 (13)
0110
0011
0001

13-6-3-1=3

得到

0011

就是数字 3。

第二步

得到

BX_(x)

之后，

每个 nibble 都已经是

0~4

例如

0001 0010 0011 0000

表示

1
2
3
0

然后

BX_(x)+(BX_(x)>>4)

就是把相邻 nibble 加起来。

再

&0x0F0F0F0F

去掉进位。

于是每个 byte 都变成

低 nibble + 高 nibble

即

每个 byte 中 1 的数量

范围

0~8
为什么 %255

此时四个 byte 分别是

b3 b2 b1 b0

每个都是

0~8

组成

b3<<24
+b2<<16
+b1<<8
+b0

而

256 ≡ 1 (mod 255)

因此

b3*256³
+b2*256²
+b1*256
+b0

≡ b3+b2+b1+b0 (mod255)

于是

%255

就把四个 byte 的值全部相加了。

这正是整个 32 位整数中 1 的总数。

由于 32 位整数最多只有 32 个 1，结果不会超过 32，因此不会与 255 取模产生歧义。

举个例子

假设

x = 0xF0F0000F

四个字节分别有

11110000 -> 4
11110000 -> 4
00000000 -> 0
00001111 -> 4

经过 BX_ 后：

04040004

再经过

+(>>4)
&

得到

04040004

（每个 byte 已经表示该字节中的 1 的数量。）

最后

4+4+0+4=12

所以

BITCOUNT(x)=12
与现代编译器相比

这段代码来自早期的位运算技巧（又称 bit twiddling hacks），在没有硬件支持和编译器内建函数时非常有价值。

现代编译器通常提供更高效的方法，例如：

__builtin_popcount(x)      // GCC、Clang
__builtin_popcountl(x)
__builtin_popcountll(x)

在支持 POPCNT 指令的处理器上，这些内建函数通常会直接生成一条硬件指令，速度通常比这种宏更快，也更易读。对于嵌入式平台，如果处理器没有专门的位计数指令，这类无循环的算法仍然具有参考价值。
#+end_example
